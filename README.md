# MTH1W coding lessons – Trinket replacement
- activities/*.html : 10 standalone Python editors (Skulpt 1.2.0 from jsDelivr, Python 2 mode so the lessons' `print "..."` syntax works). Run / Check / Reset, code autosaves in the browser.
- lesson-1-introduction-to-python.html, lesson-2-exploring-relationships.html : paste into Canvas HTML editor. Replace `https://YOUR-HOST-HERE/mth1w-coding/` with your real host URL.
- preview-all.html : both lessons with editors inlined (open locally to test; not for Canvas).
- build/ : activities.py (starter code + checks), template.html, build.py (edit BASE then `python3 build.py`), test.js/realpy.py (tests).
