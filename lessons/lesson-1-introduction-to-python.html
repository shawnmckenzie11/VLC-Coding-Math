A computer program is a series of instructions, written in words, numbers and symbols. Just like any spoken sentence is in a human language like English or French, every computer program is in a programming language. A few popular programming languages are Python (what we will teach here), C++, JavaScript and PHP.

Why Python?

We have chosen to teach Python since it is both simple enough for beginners and powerful enough to be used by modern companies. All programming languages use the same general principles, so after you know any one language, you can learn others more quickly!

The Basics: Variables, Printing, and Aritmethic

Printing

Use the print function to display text or numbers on the screen. To print text, include your message inside of double quotations " "

Example:

print "Hello, Grade 9 Math!"

Try it: Write a print statement that displays your favourite number or a greeting message. Remember to press the run button to run the program.

Variables

A variable is a "container" that holds information, like numbers or words.

Here’s how to create a variable by assigning it a value:

name = "Alex"
age = 14

In this example, name stores "Alex" and age stores the number 14.

We can use these variables in a print statement to display them to the screen. 

print name
print age

 To print variables and text at the same time use commas to include all of the items you'd like printed:

print "Hello, my name is", name
print "I am", age, "years old"

Comments

Comments are notes in the code to explain what it does, and they start with #. You may have noticed some comments in the code snippets above.

Example:

# This is a comment
# The next line prints a greeting message
print "Welcome to Python!"

Basic Math Operations

Python can do math! Here are the basic operators:

  • + for addition
  • - for subtraction
  • * for multiplication
  • / for division
  • ** for exponents

Example:

a = 10
b = 5
print "Addition:", a + b  # Adds a and b
print "Subtraction:", a - b  # Subtracts b from a
print "Multiplication:", a * b  # Multiplies a by b
print "Division:", a / b  # Divides a by b
print "Powers:", a**b  # Raises a to the power of b

Try it: Create two variables with numbers and perform each math operation on them.
