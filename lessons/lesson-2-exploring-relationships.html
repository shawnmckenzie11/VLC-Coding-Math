Step 4: Introducing Loops for Efficiency

Instead of repeating the same lines for each time, we can use a loop. A loop lets us repeat an action without retyping the code each time. This is especially useful if we want to check the height at many time points.

In Python, the for loop can go through a list of times we want to calculate, like 0, 1, 2, 3, 4 seconds.

Example:

# loop through each time
for t in [0, 1, 2, 3, 4]:  
    height = -4.9 * t ** 2 + 20 * t + 2
    print "At t =", t, "seconds, height =", height, "meters"
print "We're done!"

Here, for t in [0, 1, 2, 3, 4] means “for each t in the list [0, 1, 2, 3, 4], calculate the height and print it.” This is more efficient than writing separate lines for each time. Copy this code into the editor below to see how a loop calculates the height at each second.

Did you see the height and time line printed five times? If not, double check that your height... and print... lines are indented. Python uses indentation to specify what lines of code lie within the loop. By indenting these two lines we are telling Python to execute these lines of code every time through the loop. Notice that "We're done!" is only printed once to the screen since it is not indented (it's not inside the loop).

 

Step 5: Going Further - Adding More Time Points

Now that we know how to use a loop, we can calculate the height for more times. What if we want to know the height at every half-second up to 5 seconds?

Here’s how we can modify the loop:

for t in [0, 0.5, 1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, 5]:
    height = -4.9 * t ** 2 + 20 * t + 2
    print "At t =", t, "seconds, height =", height, "meters"
